# TPFinalLibre
1° Compile con 'javac *.java' si es que hubo un error de transferencia/descarga.
2° Ejecute dentro de la carpeta de TPFinal/TPF 'java Main.java'.
3° Ingrese datos pedidos (si quiere cargar un archivo recuerde que tiene que marcar las magnitudes del tablero que quiere cargar).
4° Al ingresar ruta recuerde que SO(sistema operativo) esta usando, ya sea windows, linux o macOS, ya que esto altera la ruta que tiene que utilizar:
  Ej: Windows: 'C:\Usuarios\[NombreDeUsuario]\Documentos\tablero.txt' o 'C:\Usuarios\[NombreDeUsuario]\Descargas\tablero.txt'.
      Linux: '/home/usuario/Documentos/tablero.txt' o '/home/usuario/Descargas/tablero.txt'.
      MacOS: '/Users/nombre_de_usuario/Documents/tablero.txt' o '/Users/nombre_de_usuario/Downloads/tablero.txt'.
5° Al terminar de dar la ruta, se ejecutara una ventana la cual:
  Tiene botones de 'Start', 'Stop', 'Step' y un panel de velocidades.
  Start: iniciar o continuar juego/generación.
  Stop: detener la juego/generación.
  Step: forzar generación, obtenemos generación de manera manual.
